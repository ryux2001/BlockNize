# BlockNize interface

## Existing visual language

The web client carries the Android dark theme into a responsive browser workspace. The web layout adapts to wider screens, while keeping the same quiet surfaces, high-contrast text, green accents, and compact labels used by the Android app.

## Color

- Page background: `#000000`.
- Primary surface: `#101010`.
- Raised surface: `#191919` to `#252525`.
- Main text: `#FFFFFF`.
- Secondary text: `#B8B8B8`.
- Green accent: `#4BDD80` for the default green Android accent.
- Selected navigation container: `#484256` with light icon and label.
- Borders: `#303030`, with `#747474` reserved for visible outlines.

The app may later expose another user-selected Android accent. Avoid status color alone as the only way to communicate success or error.

## Typography

Use the platform UI sans-serif stack, medium-weight headings, and tabular numerals for times. Body copy uses at least 16px. Reuse the Android vocabulary and Spanish labels such as «Hoy», «Calendario», «Semanas», «Registro» and «Cuenta».

## Surfaces and controls

Use full-surface dark panels for agenda entries and forms, with restrained 12–16px rounding. Keep controls legible with visible keyboard focus. Selected navigation uses the Android lavender container and green label. Avoid decorative shadows and gradient fills.

## Responsive behavior

Desktop uses a fixed navigation rail and a centered, readable workspace. Narrow screens replace the rail with a bottom navigation bar, show one calendar day at a time, and retain comfortable touch targets.
